# מסלול אבני בניין

מערכת לניהול ידע ומעקב אחרי אבני בניין טכנולוגיות לחלל, לפי המתודה של צוות CTO.
**המערכת בלמ"ס. אין להזין בה מידע מסווג.**

## מבנה
- `index.html`: האפליקציה כולה (דף אחד, בלי בנייה). מתפרסם ב-GitHub Pages.
- `supabase/schema.sql`: טבלאות, הרשאות (RLS) ושומר סיווג שחוסם תוכן בשלבים מסווגים.
- `supabase/seed.sql`: הגדרת המתודה הראשונית (טיוטה) ורשימת הצוות.

## הקמה
1. ב-Supabase: מריצים את `schema.sql` ואז את `seed.sql` (אחרי שמוסיפים את מיילי הצוות).
2. ב-Supabase, תחת Authentication: יוצרים משתמש עם סיסמה לכל חבר צוות.
3. ב-`index.html`: ממלאים `SUPABASE_URL` ו-`SUPABASE_ANON_KEY` (המפתח הציבורי בלבד, לעולם לא service_role).
4. ב-GitHub: Settings → Pages → Deploy from branch → `main` / root.

בלי הגדרות Supabase הדף עובד במצב מקומי עם נתוני דוגמה פיקטיביים.

## הרשאות
- רק מי שמופיע ב-`team_members` רואה נתונים.
- `admin` ו-`member` עורכים, `viewer` (למשל דרג בכיר) צופה בלבד.
- בשלבים מסווגים (`cls='c'`) המסד דוחה כל תוכן, ונשמרים רק סטטוס ומצביע לרשת הסגולה.
